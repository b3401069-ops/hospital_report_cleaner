# 彙整版規則與驗收口徑

依院內提供的1151028彙整版Excel與兩份設計說明實作於`case-manager`模式。原始檔、病人資料與範本不放Git。舊`clean`模式未改成這組規則。

## 操作

執行`個管報表.bat`，或指定`--source`完整來源資料夾。預設輸出檔名維持`output/癌症個案治療整合查詢表.xlsx`，不需下載含病人資料的範本。

輸出的人工確認／期別確認頁只是查閱快照。永久確認請填`review/個管人工確認.xlsx`或`review/病人期別確認.xlsx`，存檔關閉後重跑。不要把同事範本中的確認鍵直接貼入獨立檔；現有確認鍵還包含病歷號及事件條件，避免同個案不同條件誤套。新規則拆分的待辦須重新確認，已填舊紀錄保留稽核。

## 規則

|項目|本版口徑|
|---|---|
|計畫比對|手術、放療、化療、標靶、免疫、抗荷爾蒙、TACE、RFA雙向比對有無。手術僅乳、腸、肺、肝、攝護腺、膀胱癌；Class 0不比對。不是院內指引符合性。|
|藥物|OMET3／Methotrexate 2.5mg不算化療；注射劑沿用化療規則。指定支持性用藥留未分類並註記，不觸發未分類提醒。學名去劑量與常見鹽類；未辨識商品名不猜成分。|
|計畫用藥|字典辨識學名，加FOLFOX、CapeOX、EpiC/EC、Lenozole、Tagrisso、UFUR。未辨識文字仍保留原計畫，不宣稱字典涵蓋全部處方。|
|肝癌計畫|放療不採「放療其他說明」；該欄TAE/TACE/RFA仍作預定栓塞／燒灼提示。|
|首療|診斷前30天起最早治療醫令；術後化療180天內、術後照射365天內。醫令不等於實際完成。|
|放療中斷|36011B/36012B照射日相鄰≤21天，間隔缺≥5工作日。停照期間至恢復後3天內有36015B，列黃色重新計畫暫停。|
|假日|holidays 0.86 TW，至少2019～2027年，含補假與彈性放假。扣週末；補班週六仍非工作日；颱風假及院內休診未扣。|
|完成度|最近一筆有分次數計畫，取最大1～45 fx/fr/fractions/次或Gy x N。計畫前30天至下一份計畫前；60天內連續填寫同組。加總期間照射日，排除計畫後新療程；<80%且停照>14天列未完成。無照射只寫查無，不推定未完成。|
|分段處方限制|15fx＋boost 5fx取15，不取20，必須核對原處方；同日多碼僅算一照射日。36022B不作分次數。|
|新療程|同類放療／化療／標靶／免疫間隔>60天，手術／TACE／RFA>30天；起始距此前最近計畫>183天提醒。抗荷爾蒙、Class 0不列。|
|CCRT|照射日間隔≤30天一段，起訖前後7天有化療即疑似同步；次數為不同日期數。|
|必要提報|指定治療最後一次至死亡0～30天疑似提報。死亡(未治療)排除；各別治療目的皆明確Palliative時才排除該項。混合目的不自動排除。不是認證提報決定。|
|MDT|第三四期或計畫復發，無會議日期則提醒。|
|追蹤|新確診30天；已有診斷後追蹤則每6個月。未回診>90天疑似失聯。已死亡／結案免追蹤，癌別空白不判斷。|
|待辦|Class 0轉院／未治療死亡／拒治全部排除。其他Class 0結案／任何轉院只保留適用的計畫缺漏與新療程；Class 0本身不產新療程。期別空白（含僅TNM）仍提醒，保留原安全設計。|
|統計|一個癌症個案一列，非獨立病人人數；癌別空白排除。符合率=是/(是+否)。首療分母限-30～365天有首療資料；無分母留空。|

## 與參考檔的差別

- 不將輸出報表當永久輸入，確認檔保持獨立並備份；不自動套用來源不明的舊版確認鍵。
- 保留期別來源衝突提醒與僅TNM缺期別提醒，不因範本只列「未填」而漏掉需要核對的個案。
- 缺乏實際給藥、療程識別碼及精確癌別連結時，只輸出疑似結果。多癌別通用醫令不可跨個案加總。
- 原始資料期間決定截止日，不把範本的2026/10/20硬套在只有9月底來源的資料。
- 沒有醫療端獨立驗證其臨床適用性；上線前仍需個管師／醫療端抽查。

假日來源：[holidays Taiwan文件](https://holidays.readthedocs.io/en/main/auto_gen_docs/taiwan/)。套件版本固定，升級需重新驗證假日及邊界測試。
